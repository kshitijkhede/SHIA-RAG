Pipeline summary — physical text blocks extracted, and the semantic hierarchy induced from them.

1 · Reading-order recovery (column-gutter algorithm)

Naive top-to-bottom extraction jumps across columns; the gutter algorithm reads each column in order. Lower inversion % = closer to the correct reading order. ROM = reading-order monotonicity.

Column-gutter (ours)

2 · Induced concept hierarchy

Section numbering is the primary attachment signal; the semantic Parent-Ranking Engine (PRE) is the fallback for unnumbered headings. Each node carries a KCE confidence score.

3 · Graph-validation guarantees

Every candidate edge passes the validator before it is added, so the hierarchy is structurally sound by construction.
